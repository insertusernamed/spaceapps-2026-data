# Ontario boundary

`ontario.geojson` is the Ontario feature from the geoBoundaries gbOpen Canada
ADM1 simplified GeoJSON, release commit `41af8f1`.

- Metadata: https://www.geoboundaries.org/api/current/gbOpen/CAN/ADM1/
- Download: https://github.com/wmgeolab/geoBoundaries/raw/41af8f1/releaseData/gbOpen/CAN/ADM1/geoBoundaries-CAN-ADM1_simplified.geojson
- Upstream: Statistics Canada, 2016 provincial/territorial boundaries.
- Upstream licence reported by geoBoundaries: Open Government Canada 2.0.
- Attribution: Statistics Canada and geoBoundaries (https://www.geoboundaries.org/).

The simplified boundary is used as a spatial filter, preserving entire fields
that intersect Ontario. Fields crossing the provincial border remain whole;
this is not a cadastral or jurisdiction determination.
